## Comandos de observación, nunca una instalación

Son instrucciones para un operador futuro autorizado en el destino cuya identidad ya fue acreditada; no se han ejecutado. No pegar el bloque completo como script. Elegir sólo la inspección correspondiente, registrar comando exacto, hora UTC y exit code. Incluso lectura privilegiada requiere alcance aprobado. No usar sudo automático ni instalar herramientas faltantes. Salida original privada; publicar exclusivamente extractos revisados.
